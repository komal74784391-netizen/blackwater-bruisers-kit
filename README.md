# Blackwater Bruisers Design Kit

Official brand and design package for the Blackwater Bruisers of the Rivergate
Roller Derby League.

## Contents

- `palette/tokens.css` — club color tokens and type stack
- `palette/palette.json` — machine-readable palette
- `assets/primary-crest.svg` — approved crest
- `assets/wordmark.svg` — horizontal wordmark
- `docs/usage.md` — print and digital usage rules
- `package.json` — package metadata

## Release status

Version 2.1.0 is published for the 2026 season and replaces all previous club
artwork. Every file here is final and approved.
